# 🎬 Влад Сапунов — Портфолио видеооператора

## Стек
- **Frontend**: Next.js 16 + Tailwind CSS 4 + TypeScript + Framer Motion + **Lenis Smooth Scroll**
- **Типографика**: **Geist Mono**
- **Админ-панель (`/admin`)**:
  - **Заглушка изображений**:
    * В `public/placeholder.png` сохранена загруженная заглушка.
    * Во всех карточках (Hero reels, Все работы, Обо мне, Клиенты) при отсутствии изображения или ошибке загрузки (`onError`) автоматически отображается заглушка `/placeholder.png`.
  - **Левый сайдбар (`<aside>`)**:
    * **Обводка отключена (`border-none`)**, маргины: `marginTop: 12px`, `marginBottom: 12px`, `marginLeft: 12px`, высота `calc(100vh - 24px)`.
  - **Плавающие кнопки плюсик и «СОХРАНИТЬ»**:
    * Прижаты друг к другу (`gap-0`).
    * Ховер на плюсик: фон синий `#1458E6`, иконка белая.
    * Ховер на «СОХРАНИТЬ»: фон белый `#FFFFFF`, текст черный `#000000`.
  - **Раздел «Услуги»**:
    * Убрана подчеркивающая линия и лишний текст.
    * Названия карточек: Карточка №1 (синяя), Карточка №2 (белая), Карточка №3 (черная), Карточка №4 (синяя).
  - **Раздел «Обо мне»**:
    * Убраны подчеркивающие линии в верхнем и нижнем блоках.
    * Инпуты/текстареи увеличены (`rows={8}`), чтобы текст отображался без внутреннего скролла.
  - **Раздел «Клиенты»**:
    * Убраны подчеркивающие линии.
  - **Раздел «FAQ»**:
    * Верхняя кнопка «Добавить вопрос» убрана, добавление происходит через нижний плюс.
    * Все новые вопросы и элементы добавляются в самый верх списка.
  - **Псевдоотступ снизу**:
    * Добавлен во всех разделах (`h-[100px]`), чтобы плавающий блок кнопок не перекрывал контент.

- **Сайт (Клиентская часть)**:
  - **Клиенты**: ховер изолирован только на тексте названия клиента (логотип и точка-разделитель не входят в ховер). Первый клиент: «Петербургский нефтяной терминал» целиком.
  - **Обо мне**: фотография растянута на всю ширину правой части.
  - **FAQ**: падинги по 8px слева и справа в полосе вопроса и контенте.
  - **Сайдбар**: маргины по 12px сверху, снизу и слева.
